# 海龟策略买入法

> 版本：1.0 | 更新日期：2026-04-23

---

## 一、核心逻辑

**趋势一旦形成，大概率延续**。在突破时买入，顺势而为。

---

## 二、入场信号

### 系统1 - 短线（推荐）

```
买入条件：收盘价突破过去20日最高价
过滤条件：若上次突破交易盈利，跳过本次信号（避免震荡磨损）
```

### 系统2 - 长线

```
买入条件：收盘价突破过去55日最高价
过滤条件：无，所有信号都执行
```

---

## 三、突破确认条件

| 条件 | 标准 | 说明 |
|------|------|------|
| 突破K线 | 收盘价 > 20日最高价 | 不用盘中最高价，等收盘确认 |
| 成交量 | 突破日量 > 20日均量 × 1.5 | 放量确认，过滤假突破 |
| 趋势背景 | MA20 > MA60 | 多头排列，排除下跌趋势中的反弹突破 |

---

## 四、分批建仓规则

海龟策略的核心：**逐步建仓，验证趋势**

| 批次 | 触发条件 | 仓位比例 | 说明 |
|------|---------|---------|------|
| 第1笔 | 突破确认 | 25% | 试探建仓 |
| 第2笔 | 盈利 +0.5×ATR | 25% | 趋势验证，加仓 |
| 第3笔 | 再盈利 +0.5×ATR | 25% | 趋势确立，加仓 |
| 第4笔 | 再盈利 +0.5×ATR | 25% | 满仓 |

**ATR加仓示例**：
```
入场价：100元，ATR(14) = 3元

第1笔：100元买入25%仓位
第2笔：100 + 1.5 = 101.5元加仓25%
第3笔：101.5 + 1.5 = 103元加仓25%
第4笔：103 + 1.5 = 104.5元加仓25%

止损价始终 = 首笔入场价 - 2×ATR = 94元
```

---

## 五、单笔仓位计算

**风险等权原则**：每笔交易承担相同风险

```
单笔买入金额 = 总资金 × 单笔风险比例 / (入场价 - 止损价) × 入场价
```

**参数设定**：
- 单笔风险比例：建议 1-2%（即单笔亏损不超过总资金1-2%）
- 止损距离：2×ATR(14)

**示例**：
```
总资金：100万
单笔风险：1%（1万元）
入场价：100元
ATR(14)：3元
止损价：94元（100 - 2×3）

单笔买入金额 = 1万 / (100-94) × 100 = 16.67万元
买入股数 = 16.67万 / 100 = 1667股
```

## 六、执行清单

- [ ] 确认收盘价突破20日最高价（或55日）
- [ ] 确认成交量 > 20日均量 × 1.5
- [ ] 确认MA20 > MA60（多头趋势）
- [ ] 计算ATR(14)和止损价
- [ ] 按风险等权计算买入金额
- [ ] 首笔买入25%仓位
- [ ] 记录加仓价格线（+0.5×ATR间隔）
- [ ] 设置止损价 = 入场价 - 2×ATR

---

## 七、优缺点

| 优点 | 缺点 |
|------|------|
| 趋势行情收益高 | 震荡市连续止损 |
| 规则明确，易执行 | 信号较少，需耐心 |
| 有加仓逻辑，利润奔跑 | 突破买入成本较高 |
| 与海龟止损完美配套 | 需要严格纪律 |

---

## 八、决策流程图

```
监控股票池
    ↓
收盘价突破20日最高价？
    ↓ 否 → 继续监控
    ↓ 是
成交量 > 1.5倍均量？
    ↓ 否 → 忽略（可能假突破）
    ↓ 是
MA20 > MA60？
    ↓ 否 → 忽略（非趋势）
    ↓ 是
计算ATR和止损价
按风险等权计算仓位
买入第1笔（25%）
设置加仓价格线
    ↓
止损或加仓
```

---

> **一句话总结**：突破20日高点 + 放量 + 趋势确认 → 分批建仓 → 止损入场价-2×ATR
