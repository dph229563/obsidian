# 优质公司 × 海龟交易系统 适配性分析报告

> 分析日期：2026-04-27  
> 交易规则：海龟交易系统（系统1）- 趋势跟踪  
> 分析标的：可交易A股（主板7家 + 创业板2家 + 科创板1家）

---

## 一、海龟系统对标的的要求

| 维度 | 理想特征 | 原因 |
|:-----|:---------|:-----|
| **波动性** | 中等偏高 | ATR不能太小（止损易被噪音触发），也不能太大（单笔风险过高） |
| **趋势性** | 强 | 收盘价突破20日高点的信号需要后续趋势延续才能盈利 |
| **流动性** | 好 | 需分批加仓（最多4单位），日成交额需充足 |
| **行业属性** | 成长/周期 | 容易形成持续趋势，而非震荡 |

**系统核心逻辑**：
- 突破20日最高点 → 买入第1单位
- 每盈利0.5N加仓1次（最多4次）
- 止损价 = 最新入场价 - 2N（随加仓上浮）
- 跌破10日最低点 → 平仓离场

## 四、操作建议

### 新建仓位优先顺序

```
首推：工业富联 (601138) → 北方华创 (002371)
次推：汇川技术 (300124) → 思源电气 (002028)
备选：立讯精密 (002475) → 澜起科技 (688008) → 恒瑞医药 (600276)
```

### 组合配置建议

假设您计划持有4-6个标的：

| 仓位比例 | 建议标的 | 说明 |
|:---------|:---------|:-----|
| 25% | 工业富联 | 核心持仓，AI主线 |
| 20% | 北方华创 | 科技成长，半导体设备 |
| 20% | 汇川技术 | 制造业升级趋势 |
| 15% | 思源电气 | 稳健型，电网投资 |
| 10% | 立讯精密 | 周期型，注意节奏 |
| 10% | 澜起科技/恒瑞医药 | 灵活配置 |

### 风险提示

1. **工业富联、北方华创、澜起科技**：科技股波动大，严格执行2N止损
2. **立讯精密**：关注苹果产业链周期和新品发布时间
3. **恒瑞医药**：关注创新药研发进展和政策风险
4. **汇川技术、思源电气**：制造业周期相对较长，可耐心持有

---

## 五、一句话总结

> **首选工业富联 + 北方华创，次选汇川技术 + 思源电气，避开长江电力和宁波银行。**

海龟系统需要波动性适中的趋势型标的，科技股和成长型制造业最适合，而低波动的公用事业和银行股不适合。
