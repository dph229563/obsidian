# 止盈止损策略详解

> 版本：1.0 | 更新日期：2026-04-23
> 来源：简洁交易规则

---

## 一、止损策略

### 1. 单笔止损

#### 主策略：海龟止损法

```
止损价 = 入场价 - 2 × ATR(14)
```

**ATR(14) 说明**：
- ATR = Average True Range（14日平均真实波幅）
- 参数14为标准周期，兼顾灵敏度和稳定性
- 周期越短（如ATR(7)）越灵敏但易误触
- 周期越长（如ATR(20)）越稳定但止损较宽

**示例**：
| 入场价 | ATR(14) | 止损价计算 | 止损价 |
|-------|---------|-----------|--------|
| 100元 | 3元 | 100 - 2×3 | **94元** |
| 50元 | 1.5元 | 50 - 2×1.5 | **47元** |
| 200元 | 8元 | 200 - 2×8 | **184元** |
| 基本面恶化 | 立即清仓 | 业绩暴雷/政策利空，不犹豫 |

---

### 2. 保本止损（浮盈10%启动）

**规则**：当浮盈超过 **10%** 后，止损价自动上移至入场成本价，确保这笔交易至少不亏钱。

**示例**：
```
买入价：10元
初始止损价：9.4元（入场价 - 2×ATR）

涨到11元（浮盈10%）→ 止损价上移至10元（成本价）
后续最低跌到10元触发止损 → 保本出场，不亏钱
```

**核心逻辑**：
| 浮盈阶段 | 止损价 | 保护目标 |
|---------|--------|---------|
| 浮盈 < 10% | 入场价 - 2×ATR | 保护本金，接受有限亏损 |
| 浮盈 ≥ 10% | 入场成本价 | 保护利润，确保不亏 |

---

### 3. 止损策略特点

| 特点 | 说明 |
|------|------|
| **动态适配** | 用ATR而非固定比例，适应不同波动率股票 |
| **分层控制** | 单笔止损控个股风险，总仓位止损控整体风险 |
| **保本机制** | 浮盈10%后止损上移至成本价，确保不亏 |
| **底线明确** | 总亏损12%强制清仓，防止深套 |
| **波动友好** | 高波动股止损宽，低波动股止损窄，避免误触 |

## 二、止盈策略

### 1. 分档止盈（浮盈20%启动）

| 利润阶段 | 触发条件 | 操作 | 说明 |
|---------|---------|------|------|
| 浮盈 20-40% | 回撤 6% | 卖出 30% | 锁定首批利润 |
| 浮盈 40-80% | 回撤 8% | 卖出 40% | 放宽回撤空间 |
| 浮盈 > 80% | 回撤 10% | 卖出剩余 | 吃满主升浪 |
| 基本面恶化 | 立即清仓 | 业绩暴雷/政策利空，不犹豫 |


**核心逻辑**：
- 浮盈越多 → 允许的回撤空间越大
- 分批卖出 → 既锁定利润又吃到主升浪

**示例**：
```
买入价：10元，买入1000股

阶段1：涨到12-14元（浮盈20-40%）
  → 从最高价回撤6%时卖出300股

阶段2：涨到14-18元（浮盈40-80%）
  → 从最高价回撤8%时卖出400股

阶段3：涨到18元以上（浮盈>80%）
  → 从最高价回撤10%时卖出剩余300股
```

### 3. 止盈策略特点

| 特点 | 说明 |
|------|------|
| **启动门槛** | 浮盈20%才开始监控，避免小波动频繁交易 |
| **移动止盈** | 止盈线随最高价上移，让利润奔跑 |
| **分档操作** | 随浮盈增加，容忍更大回撤，减少被洗出局 |

## 四、执行要点

### 止损执行

- [ ] 入场时立即设定止损价 = 入场价 - 2×ATR(14)
- [ ] 记录止损价到交易日志
- [ ] 浮盈达到10%后，止损价上移至成本价（保本止损）
- [ ] 盘中跌破止损价坚决执行，不犹豫

### 止盈执行

- [ ] 浮盈达到20%后开始监控
- [ ] 记录最高价，动态更新止盈线
- [ ] 选择分档版或简化版，提前确定
- [ ] 回撤触发时坚决执行，不贪心

---

## 五、一句话总结

**止损**：入场价 - 2×ATR(14)，浮盈10%后上移至成本价保本

**止盈**：浮盈20%启动，分档回撤止盈，让利润奔跑
