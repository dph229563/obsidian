# 海龟交易规则（系统1）

> 版本：2.0 | 更新日期：2026-04-24
> 核心原则：趋势跟踪，突破买入，跌破离场

---

## 一、核心逻辑

**趋势一旦形成，大概率延续。不预测，只跟随。**

| 原则 | 说明 |
|------|------|
| 突破进场 | 收盘价突破20日最高价时买入 |
| 趋势加仓 | 盈利0.5N后加仓，验证趋势 |
| 跌破离场 | 收盘价跌破10日最低价时平仓 |
| 小亏大赢 | 靠少数大趋势赚钱，接受大量小止损 |

---

## 二、入场信号

### 主信号

```
买入条件：收盘价突破过去20日最高价
```

### 过滤规则

**上次突破交易盈利 → 跳过本次信号**

原因：避免震荡市连续假突破造成的磨损。

---

## 三、突破确认（可选过滤）

| 条件 | 标准 | 说明 |
|------|------|------|
| 成交量 | 突破日量 > 20日均量 × 1.5 | 放量确认，过滤假突破 |
| 趋势背景 | MA20 > MA60 | 多头排列，排除下跌趋势反弹 |

---

## 四、加仓规则

价格向有利方向每波动 **0.5N**，加仓1单位，最多4单位。

### 加仓示例

```
入场价：100元，ATR(14) = 3元，N = 3

第1笔：100元买入 1单位，止损价 = 100 - 6 = 94元
第2笔：101.5元加仓 1单位，止损价上移至 101.5 - 6 = 95.5元
第3笔：103元加仓 1单位，止损价上移至 103 - 6 = 97元
第4笔：104.5元加仓 1单位（满仓），止损价上移至 104.5 - 6 = 98.5元

注：每次加仓后，整体仓位的止损价调整到最新入场价 - 2N
```

---

## 五、止损规则（浮动止损）

**核心原则**：每次加仓后，止损价随最新入场价上浮，保护已有利润。

```
止损价 = 最新入场价 - 2 × ATR(14)
```

### 浮动止损示例

| 加仓次数 | 入场价 | 止损价计算 | 止损价 |
|----------|--------|------------|--------|
| 第1笔 | 100元 | 100 - 2×3 | 94元 |
| 第2笔 | 101.5元 | 101.5 - 2×3 | 95.5元 |
| 第3笔 | 103元 | 103 - 2×3 | 97元 |
| 第4笔 | 104.5元 | 104.5 - 2×3 | 98.5元 |

### 浮动止损的优势

- **保护利润**：加仓越多，止损越紧，锁定已有收益
- **风险可控**：整体仓位始终承担2N风险，不会因加仓而放大
- **顺势而为**：趋势延续时止损跟随上移，趋势反转时及时离场

**ATR查看方法**：同花顺 → 添加指标 → ATR（参数设为14）

---

## 六、离场规则

```
平仓条件：收盘价跌破过去10日最低价
```

**特点**：
- 不预设止盈目标，让利润充分奔跑
- 只有趋势反转时才离场
- 浮盈越多，容忍的回撤空间越大

---

## 七、仓位计算

**风险等权原则**：每单位仓位承担相同风险（1%账户净值）

```
单位仓位 = 1% × 账户净值 / ATR(14)
买入股数 = 单位仓位 / 入场价
```

### 示例

```
账户净值：10万
单笔风险：1%（1000元）
ATR(14)：3元
入场价：100元

单位仓位 = 1000 / 3 = 333元（波动风险）
买入股数 = 333 / 100 ≈ 3股（简化理解）

实际计算：
买入金额 = 单位仓位 × 入场价 / ATR = 1000 × 100 / 3 = 3.33万元
买入股数 = 3.33万 / 100 = 333股
```

## 九、执行清单

### 买入前

- [ ] 收盘价突破20日最高价？
- [ ] 上次突破交易是否盈利？（盈利则跳过）
- [ ] 成交量 > 20日均量 × 1.5？（可选）
- [ ] MA20 > MA60？（可选）
- [ ] 计算ATR(14)
- [ ] 计算初始止损价 = 入场价 - 2×ATR
- [ ] 计算单位仓位和买入金额
- [ ] 买入第1单位

### 持仓中

- [ ] 记录加仓价格线（每0.5N）
- [ ] 监控是否触发加仓
- [ ] 加仓后更新止损价 = 最新入场价 - 2×ATR
- [ ] 监控是否跌破止损价
- [ ] 监控是否跌破10日最低价

### 离场

- [ ] 收盘价跌破10日最低价 → 平仓
- [ ] 收盘价跌破止损价 → 止损

---

## 十、不做什么

1. **不抄底**：等待突破确认再进场
2. **不预测**：只响应已经发生的突破
3. **不追高加仓**：只在盈利0.5N后加仓，不在突破日一次性满仓
4. **不提前止盈**：浮盈再多也不主动卖出，等跌破10日最低价
5. **不抱幻想**：跌破离场线坚决执行
