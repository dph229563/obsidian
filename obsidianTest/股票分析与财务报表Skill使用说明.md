# 股票分析与财务报表 Skill 使用说明

目前安装了以下两个金融分析 Skill：

1. `stock-analysis`：股票研究与估值分析
2. `financial-statements`：财务报表编制与差异分析

二者定位不同：

> `stock-analysis` 负责从投资者视角研究公司；`financial-statements` 负责从会计和经营管理视角整理、比较财务报表。

---

## 一、stock-analysis：股票分析

### 1. 主要作用

用于建立结构化的个股研究报告，支持：

- 中国 A 股
- 港股
- 美股

它提供的是一套股票分析流程和报告模板，不是实时行情终端，也不会自动获得付费金融数据库中的数据。

### 2. 核心能力

#### 基本面分析

可以分析：

- 公司商业模式和收入来源
- 行业地位与竞争优势
- 营业收入和利润增长
- 毛利率、营业利润率、净利率
- ROE、ROIC 等资本回报指标
- 自由现金流及其增长情况
- 资产负债结构和偿债能力

#### 估值分析

覆盖的主要指标包括：

| 指标 | 含义 |
|---|---|
| PE | 市盈率，股价相对于每股收益的估值 |
| PB | 市净率，市值相对于净资产的估值 |
| PS | 市销率，适合分析尚未盈利的成长企业 |
| EV/EBITDA | 企业价值相对于息税折旧摊销前利润 |
| PEG | 市盈率相对于盈利增长速度 |
| FCF Yield | 自由现金流收益率 |

可用于：

- 判断当前估值处于偏高、合理还是偏低区间
- 与同行公司比较
- 与公司自身历史估值比较
- 分析市场已经计入了哪些增长预期

#### 技术面分析

支持的分析框架包括：

- 50 日、200 日移动平均线
- MACD
- RSI
- 趋势判断
- 支撑位与压力位
- 放量突破
- 双顶、双底、头肩形态等常见图形

技术分析需要提供近期价格、成交量或K线数据，否则只能说明方法，无法得到可靠结论。

#### 同行比较

可以比较多家公司在以下方面的差异：

- 收入与利润增速
- 盈利能力
- 估值水平
- 负债和现金流
- 市场份额
- 技术壁垒
- 行业位置

#### 风险与情景分析

可以整理：

- 核心投资逻辑
- 看多情景（Bull Case）
- 中性情景（Base Case）
- 看空情景（Bear Case）
- 公司特有风险
- 行业周期风险
- 政策、技术和估值风险

### 3. 可以生成的结果

标准报告通常包括：

1. 公司和证券基本信息
2. 核心结论摘要
3. 关键财务指标
4. 商业模式与竞争优势
5. 财务表现
6. 估值分析
7. 技术面分析
8. 同行比较
9. 风险因素
10. 多空情景

### 4. 推荐输入

为了提高分析质量，最好提供：

- 股票名称和代码
- 所属市场
- 希望分析的时间范围
- 投资期限：短期交易或长期投资
- 最近3—5年的财务数据
- 当前股价和历史行情
- 希望比较的同行公司
- 特别关注的问题

### 5. 使用示例

```text
请使用 stock-analysis 分析中际旭创（300308）。

重点分析：
1. AI 光模块业务的竞争优势；
2. 最近三年的收入、利润和现金流；
3. 与新易盛、天孚通信的估值对比；
4. 当前估值隐含的增长预期；
5. 主要风险和三种情景。

请使用截至分析日能够核验的最新公告和财报。
```

```text
请使用 stock-analysis 对寒武纪进行基本面分析。
不要做技术分析，重点判断收入增长、亏损收窄、研发投入、
客户集中度、现金流和估值风险。
```

### 6. 局限与注意事项

- Skill 本身不能保证获得实时股价。
- 不具备内幕信息或付费机构数据库权限。
- 技术指标必须基于准确、足量的行情数据。
- 估值结果依赖盈利预测和折现假设。
- Skill 中类似“PE 小于15倍偏低”等固定阈值只能作为示例，不能跨行业直接套用。
- 银行、保险、周期股、成长股和亏损企业需要采用不同的估值方法。
- 输出是研究辅助材料，不是收益承诺或买卖指令。

## 二、financial-statements：财务报表分析

### 1. 主要作用

这个 Skill 主要服务于企业财务、会计结账和经营分析，用于：

- 编制利润表、资产负债表和现金流量表
- 对比本期、上期、去年同期及预算
- 计算金额和百分比差异
- 识别重大异常项目
- 分析变化原因
- 生成管理层财务摘要

它采用的参考框架偏向美国 GAAP 和 IFRS。分析中国上市公司时，应结合中国企业会计准则及上市公司公告口径。

### 2. 支持的报表期间

| 类型 | 用途 |
|---|---|
| 月度 | 当月与上月、去年同期比较 |
| 季度 | 本季度与上季度、去年同期比较 |
| 年度 | 本年度与上一年度比较 |
| 年初至今（YTD） | 本年累计与去年同期累计比较 |

### 3. 核心能力

#### 三大财务报表

能够辅助整理：

- 利润表
- 资产负债表
- 现金流量表

#### 差异计算

可以计算：

- 金额差异：本期金额减去比较期金额
- 百分比差异
- 利润率变化
- 基点变化（Basis Point）
- 实际值与预算值差异

#### 重大差异识别

可按照金额、百分比或组合条件设定重要性阈值，例如：

- 大型科目：关注超过5%的变化
- 中型科目：关注超过10%的变化
- 小型科目：关注超过15%的变化

实际阈值应根据企业规模、科目波动性和分析目的调整。

#### 变化原因拆解

可以将业绩变化拆分为：

- 销量或业务量变化
- 产品价格或费率变化
- 产品结构变化
- 新增或停止的业务
- 一次性项目
- 收入或费用确认时点变化
- 汇率影响

#### 财务质量检查

可辅助识别：

- 收入增长但经营现金流恶化
- 应收账款增速高于收入
- 库存异常增加
- 毛利率明显变化
- 费用率异常
- 利润依赖非经常性项目
- 负债期限结构变化
- 资产减值和坏账风险

#### 期末调整与重分类

Skill 包含以下会计处理检查框架：

- 应计费用
- 预付和递延项目
- 折旧与摊销
- 坏账准备
- 存货减值
- 外币项目重估
- 税项计提
- 公允价值调整
- 流动与非流动项目重分类
- 合并报表内部交易抵销

### 4. 可以生成的结果

通常可以输出：

1. 带比较列的财务报表
2. 关键财务指标摘要
3. 重大差异清单
4. 差异原因说明
5. 尚待核查的问题
6. 后续调查或管理动作建议

### 5. 推荐输入

最好提供：

- 当前期间的报表数据
- 上期及去年同期数据
- 预算或预测数据
- 统一的单位和币种
- 科目口径说明
- 一次性损益项目
- 已知的会计调整或重分类

可以直接提供财报 PDF、Excel、CSV 或整理后的表格。

### 6. 使用示例

```text
请使用 financial-statements 分析这家公司2025年年报。

对比2024年，重点检查：
1. 收入、毛利率和净利率变化；
2. 应收账款和存货是否异常；
3. 经营现金流与净利润是否匹配；
4. 研发、销售和管理费用率变化；
5. 一次性损益和资产减值；
6. 列出需要进一步核实的重大差异。
```

```text
请比较这家公司最近八个季度的利润表和现金流量表，
识别收入增速、毛利率和经营现金流趋势，
并区分持续性变化与一次性因素。
```

### 7. 局限与注意事项

- 它更偏财务报表编制和经营差异分析，而不是直接判断股票是否值得买。
- 默认参考资料侧重美国 GAAP，分析A股时需要调整为中国会计口径。
- 输入数据不完整时，不能可靠推断未披露项目。
- 管理层对差异原因的解释仍需通过公告、电话会或其他证据核实。
- 报表分析无法单独判断行业空间、竞争优势和估值水平。
- 正式会计报表和监管文件应由专业会计人员复核。

## 三、两个 Skill 的区别

| 对比项 | stock-analysis | financial-statements |
|---|---|---|
| 核心视角 | 投资者 | 财务人员、经营管理者 |
| 核心问题 | 公司和股票是否具有吸引力 | 财务数据发生了什么变化 |
| 覆盖市场 | A股、港股、美股 | 不限定市场，侧重会计报表 |
| 基本面分析 | 强 | 中等 |
| 估值分析 | 支持 | 不负责 |
| 技术分析 | 支持 | 不支持 |
| 同行比较 | 支持 | 需要额外提供数据 |
| 三大报表整理 | 基础分析 | 核心能力 |
| 同比、环比、预算差异 | 支持概要比较 | 核心能力 |
| 会计调整与重分类 | 不侧重 | 支持 |
| 适合的最终产物 | 个股研究报告 | 财务报表及差异分析报告 |

## 四、组合使用方法

研究上市公司时，建议按照以下顺序组合使用：

### 第一步：financial-statements 检查财务数据

先回答：

- 收入和利润如何变化？
- 毛利率和费用率为什么变化？
- 利润是否有现金流支持？
- 应收账款、存货和负债是否异常？
- 是否存在一次性损益或会计口径影响？

### 第二步：stock-analysis 建立投资研究框架

再回答：

- 公司靠什么赚钱？
- 是否具有持续竞争优势？
- 行业空间和竞争格局如何？
- 当前估值是否合理？
- 市场预期是否过高或过低？
- 哪些事件可能证伪投资逻辑？

### 推荐组合提示词

```text
请结合 financial-statements 和 stock-analysis，
对公司名称（股票代码）进行完整研究。

第一部分：财务报表
- 对比最近三年和最近八个季度；
- 分析收入、利润率、费用率、现金流、应收账款和存货；
- 区分持续性趋势和一次性因素。

第二部分：股票分析
- 分析商业模式、行业地位和竞争壁垒；
- 与三家主要同行比较；
- 使用适合该行业的估值方法；
- 给出乐观、中性、悲观三种情景；
- 列出投资逻辑可能被证伪的条件。

所有时效性数据必须注明日期和来源。
不要给出简单买入或卖出结论。
```

## 五、使用建议

为了避免“数据看起来完整，但结论不可靠”，实际使用时应遵守以下原则：

1. 优先使用交易所公告、公司财报和监管文件。
2. 所有股价、估值和持仓数据注明具体日期。
3. 区分历史事实、管理层指引和分析预测。
4. 不使用单一估值指标判断所有行业。
5. 技术分析必须明确行情周期和数据截止时间。
6. 重要数字至少与原始财报交叉核对一次。
7. 将结论写成可验证、可证伪的假设。
