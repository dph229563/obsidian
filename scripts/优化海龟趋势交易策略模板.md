# 优化海龟趋势交易策略模板

> 版本日期：2026-06-26  
> 适用范围：A股高流动性股票、ETF、行业龙头或趋势性较强标的  
> 策略目标：在保留海龟趋势跟踪思想的基础上，降低假突破、同日加满仓、过度回撤带来的损失  
> 核心原则：先确认趋势，再小仓试错；盈利后逐步加仓，亏损时快速退出

---

## 一、适用条件

本策略适合以下标的：

1. 日均成交额较高，流动性充足。
2. 股价有明显趋势波段，而不是长期横盘低波动。
3. 基本面没有明显退市、财务造假、重大经营恶化风险。
4. 单日涨跌停较少，能正常执行止损。

不适合以下情况：

1. ST、退市风险股、流动性很差的小盘股。
2. 连续一字涨停或一字跌停的题材股。
3. 只适合做短线事件驱动、不适合趋势跟踪的股票。
4. 已经远离突破位、处于高位剧烈回撤中的股票。

---

## 二、核心参数

每只股票每日收盘后更新以下数据：

| 参数 | 计算方式 | 用途 |
|:--|:--|:--|
| 20日高点 | 最近20个交易日最高价 | 短周期突破参考 |
| 55日高点 | 最近55个交易日最高价 | 强趋势突破参考 |
| 10日低点 | 最近10个交易日最低价 | 短线趋势离场 |
| ATR(14) | 最近14日真实波幅均值 | 仓位、止损、加仓 |
| MA20 | 最近20日收盘均线 | 趋势过滤 |
| MA50 | 最近50日收盘均线 | 中期趋势过滤 |
| 20日均量 | 最近20日成交量均值 | 突破有效性确认 |

真实波幅 TR 计算：

```text
TR = max(当日最高价 - 当日最低价,
         abs(当日最高价 - 昨日收盘价),
         abs(当日最低价 - 昨日收盘价))
```

ATR(14)：

```text
ATR(14) = 最近14个交易日TR的平均值
```

---

## 三、买入规则

### 1. 主买点：收盘突破

满足以下条件才允许买入第1单位：

```text
收盘价 > 最近20日高点
```

更强的确认条件：

```text
收盘价 > 最近55日高点
```

过滤条件：

1. 收盘价必须站上MA20。
2. MA20最好高于MA50，至少不能明显向下。
3. 当日成交量最好大于20日均量的1.2倍。
4. 若次日开盘价高于突破价超过3%，不追高，等待回落或下一次信号。

### 2. 不盘中追突破

本策略不使用“盘中触价立即买入”作为主规则。

原因：

1. 盘中突破容易被冲高回落骗线。
2. A股部分趋势股单日振幅大，盘中触发后可能当天就回撤。
3. 收盘确认能过滤一部分假突破。

---

## 四、加仓规则

以 ATR 作为 N：

```text
N = ATR(14)
0.5N = ATR(14) / 2
2N = ATR(14) × 2
```

加仓价位：

| 档次 | 条件 | 操作 |
|:--:|:--|:--|
| 第1单位 | 收盘突破20日或55日高点 | 买入 |
| 第2单位 | 第1单位买入价 + 0.5N | 加仓 |
| 第3单位 | 第2单位买入价 + 0.5N | 加仓 |

加仓限制：

1. 每天最多新增1单位。
2. 最大持仓3单位，不做第4单位。
3. 加仓必须以收盘确认或次日站稳为准，不因盘中瞬间触价而连续加仓。
4. 若触发加仓价后收盘转弱，不加仓。

---

## 五、仓位规则

### 1. 单位仓位

单次最大亏损建议控制在账户净值的0.5%-1.0%。

计算公式：

```text
单单位股数 = 账户允许亏损金额 / (2 × ATR)
```

A股需要按100股整数取整。

### 2. 10万元账户示例

假设：

```text
账户净值 = 100,000元
单单位风险 = 0.8% = 800元
ATR = 4.00元
2ATR止损 = 8.00元
```

则：

```text
理论股数 = 800 / 8 = 100股
```

最大3单位：

```text
满仓股数 = 300股
```

### 3. 总仓位限制

| 层级 | 建议上限 |
|:--|:--|
| 单只股票 | 不超过账户净值30% |
| 单一行业 | 不超过账户净值50% |
| 所有趋势仓位 | 不超过账户净值70% |
| 单笔交易最大亏损 | 0.5%-1.0% |
| 单只股票最大亏损 | 2%-3% |

---

## 六、卖出规则

### 1. 初始止损

买入第1单位后：

```text
初始止损 = 买入价 - 2 × ATR
```

跌破初始止损，全部卖出。

### 2. 加仓后的保护止损

止损只上移，不下移。

建议规则：

| 持仓状态 | 止损处理 |
|:--|:--|
| 1单位 | 买入价 - 2ATR |
| 2单位 | 上移至第1单位买入价附近或略低 |
| 3单位 | 上移至整体成本附近或10日低点附近 |

注意：

1. 加仓当天不立刻把止损抬得过紧。
2. 至少等收盘确认站稳加仓价后，再调整止损。
3. 避免同日加仓、同日上移止损、同日被扫出的连续动作。

### 3. 趋势离场

当持仓已有浮盈后，使用趋势离场：

```text
趋势止盈线 = max(10日最低价, 收盘价 - 2 × ATR)
```

若收盘价跌破趋势止盈线，次日卖出或条件单卖出。

## 七、每日执行清单

### 收盘后检查

- [ ] 更新20日高点、55日高点、10日低点
- [ ] 更新ATR(14)
- [ ] 更新MA20、MA50、20日均量
- [ ] 检查是否收盘突破
- [ ] 检查是否满足成交量过滤
- [ ] 检查已有持仓是否触发止损或趋势离场

### 买入前检查

- [ ] 收盘价突破20日或55日高点
- [ ] 股价站上MA20
- [ ] MA20没有明显下行
- [ ] 次日开盘没有高开超过3%
- [ ] 当前行业仓位没有超限
- [ ] 本标的不是连续大幅拉升后的极端高位追涨

### 持仓后检查

- [ ] 每天最多新增1单位
- [ ] 不做第4单位
- [ ] 止损只上移不下移
- [ ] 跌破初始止损时无条件退出
- [ ] 浮盈后用10日低点或2ATR移动止盈

## 八、和原版海龟系统的区别

| 项目 | 原版海龟系统 | 优化版策略 |
|:--|:--|:--|
| 入场方式 | 20日突破或55日突破 | 以收盘突破为主，不盘中追价 |
| 加仓节奏 | 每上涨0.5N加1单位 | 每上涨0.5N加1单位，但每天最多加1单位 |
| 最大单位 | 通常最多4单位 | 最多3单位 |
| 止损方式 | 买入后2N止损，加仓后整体调整 | 2N止损，但加仓后延迟确认再上移 |
| 信号确认 | 价格突破为主 | 增加MA20、MA50、成交量过滤 |
| 仓位强度 | 更激进 | 更保守 |
| 适配市场 | 商品期货、趋势品种 | 更适配A股个股波动和涨跌停环境 |
| 主要优点 | 能完整吃到大趋势 | 减少假突破和快速满仓损失 |
| 主要代价 | 容易连续小亏 | 可能错过部分急涨行情 |

---

## 九、策略优缺点

### 优点

1. 避免盘中假突破触发买入。
2. 避免一天内连续加仓到满仓。
3. 单只股票风险更容易控制。
4. 适合多个股票共同筛选和执行。
5. 比原版海龟更适合A股个股的高波动特征。

### 缺点

1. 收盘确认会牺牲一部分入场价格。
2. 每天最多加1单位，可能少赚急速主升浪。
3. 过滤条件变多后，交易机会会减少。
4. 仍然无法避免趋势策略的连续小亏。

---

## 十、一句话总结

```text
优化版海龟策略 = 收盘确认突破 + 小仓试错 + 慢速加仓 + 2ATR止损 + 浮盈后移动止盈
```

它不是为了买在最低点，也不是为了预测顶部，而是为了在趋势真正走出来时参与，同时把假突破时的亏损控制在账户可承受范围内。
