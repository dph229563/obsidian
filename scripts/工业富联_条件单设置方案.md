## 三、不同资金规模的买入金额

### 💰 计算公式

```
每档买入金额 = 1% × 账户净值 × 入场价 / ATR(14)
            = 1% × 账户净值 × 入场价 / 3.0

买入股数 = 买入金额 / 入场价（取整到100股）
```

## 四、条件单设置步骤（以券商APP为例）

### 📱 条件单类型选择

| 券商 | 条件单名称 | 设置方法 |
|:-----|:-----------|:---------|
| 华泰 | 定价买入/卖出 | 价格触发+自动委托 |
| 中信 | 智能条件单 | 网格交易或定价交易 |
| 东方财富 | 条件单 | 价格条件单 |
| 同花顺 | 条件单 | 网格交易或反弹买入 |

### 🔧 具体设置步骤

#### 第一步：设置突破买入条件单

```
条件单1：突破买入（第1笔）
├── 监控价格：69.10元
├── 触发条件：最新价 ≥ 69.10元
├── 委托价格：69.15元（或市价）
├── 委托数量：300股（以10万账户为例）
├── 有效期：30天
└── 备注：海龟第1单位
```

#### 第二步：设置网格加仓条件单

```
条件单2：网格加仓（第2-4笔）
├── 价格网格：70.60元、72.10元、73.60元
├── 每格数量：300股
├── 委托方式：限价或市价
├── 有效期：30天
└── 备注：海龟加仓0.5N
```

#### 第三步：设置止损条件单（动态调整）

```
条件单3：止损保护（需随加仓调整）
├── 初始设置：卖出价 ≤ 63.10元
├── 委托数量：当前总持仓
├── 触发后操作：全部卖出
└── 备注：每加仓1次需上调1.5元

加仓后调整记录：
- 加仓第2笔后：止损价改为64.60元
- 加仓第3笔后：止损价改为66.10元
- 加仓第4笔后：止损价改为67.60元
```

#### 第四步：设置离场条件单（可选）

```
条件单4：趋势离场
├── 监控周期：每日收盘价
├── 触发条件：收盘跌破10日最低价
├── 当前10日最低：59.87元（每日更新）
├── 委托数量：全部持仓
└── 说明：跌破趋势离场，与止损条件单互斥
```

## 六、风险控制提醒

| 风险类型 | 控制措施 |
|:---------|:---------|
| **假突破** | 突破时成交量需>1.5倍均量，否则可取消条件单 |
| **连续止损** | 若上次突破盈利，本次信号需跳过 |
| **满仓回撤** | 满仓4单位后总风险约7%，需能承受 |
| **跳空止损** | 止损单可能以更低价格成交，实际亏损可能>2N |
